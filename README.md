# TempConvAllLN
The "TempConvAllLn" packages provides a collection of lightweight R functions to quickly convert temperatures between Fahrenheit, Celsius, and Kelvin scales. This package was created by me as an assignment of BIOS 524_001_Fall 2026_Biostatistical Computing course.

## Installation
You can install the development version of `tempconversion` directly from GitHub using the `remotes` or `devtools` package.

## Functions Included

The package includes six main conversion functions:
* `F_to_C()`: Fahrenheit to Celsius
* `F_to_K()`: Fahrenheit to Kelvin
* `C_to_F()`: Celsius to Fahrenheit
* `C_to_K()`: Celsius to Kelvin
* `K_to_F()`: Kelvin to Fahrenheit
* `K_to_C()`: Kelvin to Celsius

## Documentation
Full documentation for each function can be accessed within R after installation by typing:

```R
?F_to_C
```
